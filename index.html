Proof strategies

Process quantifiers one at a time, outside in.

The quantifier grid
To prove
To disprove
∃x P(x)
Name one specific x in the domain and verify P(x). Show it is in the domain.
Generic argument: “Let x be any element of the domain …” and show P(x) fails.
∀x P(x)
Generic argument: “Let x be an arbitrary …” Never pick a value.
Name one counterexample in the domain and verify P(x) is false there.

A later ∃ may depend on earlier ∀ variables (“Let y = 4x”). An earlier ∃ may not depend on a later ∀. Checking examples builds intuition but is never a proof of a ∀.

Direct

Default. Unpack definitions, do algebra, land on the definition of the conclusion.

Let x be an arbitrary integer with [hypothesis]. So x = 2k for some integer k. ← use the definition … algebra … = 2(…). Since (…) is an integer, [conclusion].

Contrapositive

For “if p then q” when the hypothesis is harder to use than the conclusion (e.g. “x² is even” vs “x is even”).

We will show the contrapositive: “For all …, if ¬q then ¬p.” Let x be an arbitrary … with ¬q. … direct proof of ¬p …

Contradiction

For “≠”, “not divisible”, “irrational”, or any claim whose negation gives you something concrete to work with.

Seeking contradiction, suppose the negation: “There exist … such that … and ¬[conclusion].” … derive something false (a non-integer equals an integer, √2 rational, x both even and odd, a given fact violated) … This contradicts …, completing the proof.

Cases

When the domain splits naturally (even/odd, sign, rational/irrational). Cases must cover everything; WLOG only when the cases are truly symmetric.

We use cases on whether x is even or odd. Case 1: x is even. So x = 2k … [conclusion]. Case 2: x is odd. So x = 2k+1 … [conclusion]. In every case, [conclusion].

Facts you may use without proof: laws of algebra; sum, difference, and product of integers are integers; a square of a real is non-negative; countability of any set shown in lecture. “Rational + rational is rational” must be proved from a/b unless the problem grants it.

MAMC · quantifiers
Which are true? Domain ℝ.
  1. ∃x ∀y  xy = −1
  2. ∀x ∃y  x·y = 1
  3. ∀x (x ≠ 0 → ∃y  xy = 1)
  4. ∃x ∃y (x² ≠ y² ∧ ∀z  xz − yz = 0)
  5. ∀x ∀y (x − y = y − x → x = y)

c and e.

(a) False: for any x take y = 2, then x² ≥ 0 ≠ −1. (b) False: x = 0 is a counterexample since 0·y = 0 for every y. (c) True: let x ≠ 0, take y = 0, then x⁰ = 1. (d) False: given x² ≠ y², take z = x + y; then xz − yz = (x + y)(x − y) = x² − y² ≠ 0. (e) True: x − y = y − x gives 2x = 2y, so x = y.

Disproving a ∀ ∃: fix an arbitrary first variable, then your choice of the second may depend on it.

Short answer · negation
Write the negation of each.
  1. For all integers x, if x is prime then x is not divisible by 7.
  2. For all reals x, y: x + y is even iff x − y is even.
  3. For all integers a not relatively prime to m, ax ≡ c (mod m) has no solutions or multiple solutions.
  4. There exists an integer x such that for all integers y, not [xy > 0 or xy < 0].

(a) There exists an integer x such that x is prime and x is divisible by 7.

(b) There exist reals x, y such that (x + y is even and x − y is odd) or (x + y is odd and x − y is even).

(c) There exists an integer a not relatively prime to m such that ax ≡ c (mod m) has at least one solution and does not have multiple solutions.

(d) For all integers x there exists an integer y such that xy > 0 or xy < 0.

The “not relatively prime” in (c) is part of the domain restriction, so it does not flip. In (d) the inner “not” cancels against the negation.

Short answer · rephrasing
Write a quantified proposition equivalent to “Every large enough integer is the sum of three squares.”

∃N ∀x [x ≥ N → ∃a ∃b ∃c  x = a² + b² + c²], with all variables integers.

“Large enough” means there is a threshold N. The threshold comes first because it must not depend on x.

SAMC · translation
L(x): x likes EECS 203. K(x, y): x knows y. Which says “There is someone who knows everyone who likes EECS 203”?
  1. ∀x ∃y [L(x) → K(y, x)]
  2. ∀x ∃y [L(x) ↔ K(y, x)]
  3. ∀x ∃y [L(x) ∧ K(y, x)]
  4. ∃x ∀y [L(y) → K(x, y)]
  5. ∃x ∀y [L(y) ∧ K(x, y)]

d.

“There is someone” is the outer ∃. “Everyone who likes 203” is a ∀ with a restricted domain, which becomes an implication inside the ∀. (a) says everyone who likes 203 is known by someone, possibly a different someone each time. (e) says everyone likes 203 and one person knows them all.

MAMC · equivalence
Which are equivalent to p → (∀x ¬Q(x) ∧ ∀y ¬R(y))?
  1. p → (¬∃x Q(x) ∧ ¬∃y R(y))
  2. p → ¬(∃x Q(x) ∨ ∃y R(y))
  3. ¬p ∨ ¬(∃x Q(x) ∨ ∃y R(y))
  4. ¬(p ∧ (∃x Q(x) ∨ ∃y R(y)))
  5. ¬((p ∧ ∃x Q(x)) ∨ (p ∧ ∃y R(y)))

All five.

(a) De Morgan on each quantifier (b) De Morgan on the inner ∧ (c) implication breakout (d) De Morgan on the outer ∨ (e) distribute p over the ∨
Proof 1 · three styles
Prove or disprove: for all integers x, y, if 3x − 4y is even then x is even.

True. Any of the three styles works; write whichever you need practice with.

Direct. Let x, y be integers with 3x − 4y even, so 3x − 4y = 2k. Then x = 2k + 4y − 2x = 2(k + 2y − x). Since k + 2y − x is an integer, x is even. Contrapositive. We show: for all integers x, y, if x is odd then 3x − 4y is odd. Let x be odd, x = 2k + 1. Then 3x − 4y = 6k + 3 − 4y = 2(3k − 2y + 1) + 1, odd. Contradiction. Suppose there exist integers x, y with 3x − 4y even and x odd. x = 2k + 1 gives 3x − 4y = 2(3k − 2y + 1) + 1, which is odd. Contradiction.

Each version announces the style and writes the rephrased statement before any algebra. That is where rubric points live.

Proof 2 · irrationals
For all reals x, y, z: if x − y + 3z is irrational and x, y are rational, then z is irrational.
Seeking contradiction, suppose there are reals x, y, z with x − y + 3z irrational, x and y rational, and z rational. Write x = a/b, y = c/d, z = e/f with integers a..f and b, d, f ≠ 0. Then x − y + 3z = (adf − cbf + 3bde) / (bdf), a ratio of integers with nonzero denominator, so rational. This contradicts that x − y + 3z is irrational, completing the proof.

Do not write “rational minus rational is rational” unless the problem grants it. Show the fraction.

Proof 3 · divisibility
Prove: for all integers a, b, if a | b and a > 1, then a does not divide b + 1.
Contradiction. Suppose there exist integers a, b with a | b, a > 1, and a | (b + 1). Then b = aj and b + 1 = ak for integers j, k. Subtracting, 1 = a(k − j), so k − j = 1/a. But k − j is an integer and 1/a is not (since a > 1). Contradiction.
Direct. Let a | b with a > 1, so b = am. Then b + 1 = am + 1 = a(m + 1/a). Since a > 1, 1/a is not an integer, so m + 1/a is not an integer, so a ∤ (b + 1).
Proof 4 · cases
Prove: for all integers x, 3x(x + 5) is even.
Let x be any integer. We use cases on the parity of x. Case 1: x even, x = 2k. Then 3x(x + 5) = 2 · [3k(2k + 5)], and 3k(2k + 5) is an integer. Case 2: x odd, x = 2k + 1. Then x + 5 = 2k + 6 = 2(k + 3), so 3x(x + 5) = 2 · [3(2k + 1)(k + 3)], an integer times 2. In both cases 3x(x + 5) is even.

Say “we use cases” and label them. Both cases must end with the exact form 2·(integer).

Proof 5 · contrapositive + cases
Reals x, y. Prove: if x − 2y is rational and xy is irrational, then x and y are both irrational. You may assume sums and products of rationals are rational, and a rational plus or times an irrational is irrational.
We prove the contrapositive: if x is rational or y is rational, then x − 2y is irrational or xy is rational. (De Morgan on both sides) Case 1: x rational, y irrational. Then 2y is irrational and x − 2y is irrational. Case 2: x irrational, y rational. Then 2y is rational and x − 2y is irrational. Case 3: x, y both rational. Then xy is rational. In every case the conclusion holds.

Negating “both irrational” gives an “or”, which is why the cases appear. All three cases are needed; they are not symmetric.

SAMC · mod calculation
Find 443 mod 15. a) 1  b) 3  c) 4  d) 8  e) 12

c) 4.

4² = 16 ≡ 1 (mod 15) 4⁴³ = 4 · 4⁴² = 4 · (4²)²¹ ≡ 4 · 1²¹ = 4

Look for a small power that is ≡ 1 or ≡ −1 first. If none, use repeated squaring and reduce after every step.

Short answer · EEA
Use the Extended Euclidean Algorithm to find the smallest nonnegative x with 15x ≡ 2 (mod 34).

x ≡ 16 (mod 34).

Down: 34 = 2·15 + 4 (1) 4 = 34 − 2·15 15 = 3·4 + 3 (2) 3 = 15 − 3·4 4 = 1·3 + 1 (3) 1 = 4 − 3 Back up: 1 = 4 − 3 = 4 − (15 − 3·4) = 4·4 − 15 = 4·(34 − 2·15) − 15 = 4·34 − 9·15 So −9·15 ≡ 1 (mod 34): the inverse of 15 is −9 ≡ 25. Multiply BOTH sides of 15x ≡ 2 by −9: x ≡ −18 ≡ 16. Check: 15·16 = 240 = 7·34 + 2 ✓

Most common lost points: stopping at the inverse instead of solving for x, multiplying only one side, or a sign slip on the way back up. Always check.

Free response · sets
Sets A, B, C with B ⊆ C. Prove (C − B) ∪ (B − A) ⊆ C using only definitions, no set identities.
Let x be an arbitrary element with x ∈ (C − B) ∪ (B − A). By definition of union, x ∈ C − B or x ∈ B − A. Case 1: x ∈ C − B. By definition of set minus, x ∈ C and x ∉ B. So x ∈ C. Case 2: x ∈ B − A. Then x ∈ B and x ∉ A. Since B ⊆ C and x ∈ B, x ∈ C by definition of subset. In every case x ∈ C. Therefore (C − B) ∪ (B − A) ⊆ C by definition of subset.

Subset proofs always start “Let x be arbitrary, suppose x ∈ left side” and end “so x ∈ right side”. Cite the definition at each step.

MAMC · sets and functions
A, B sets in universe U. f : P(A) × P(B) → P(U), f(S, T) = S ∪ T. Which could be true for some choice of A, B, U?
  1. f is one-to-one
  2. f is not one-to-one
  3. f is onto
  4. f is not onto
  5. f has an empty domain

a, b, c, d. Not e.

(a, c) A = {280}, B = {203}, U = {280, 203}: the four inputs map to ∅, {280}, {203}, {280, 203}, a bijection. (b) A = B = {203}: f(∅, {203}) = f({203}, ∅). (d) A = B = {203}, U = {203, 280}: nothing maps to {280}. (e) ∅ is a subset of every set, so (∅, ∅) is always in the domain.

Short answer · 1-1 and onto
(a) f : ℝ − {−5/4} → ℝ, f(x) = 3 / (4x + 5). Prove or disprove f is one-to-one.  (b) g : ℝ⁺ → ℝ, g(x) = 3x³ + 9. Prove or disprove g is onto.
(a) One-to-one. Let x₁, x₂ ∈ ℝ − {−5/4} with f(x₁) = f(x₂). 3/(4x₁ + 5) = 3/(4x₂ + 5). Multiply both sides by (4x₁ + 5)(4x₂ + 5): 3(4x₂ + 5) = 3(4x₁ + 5) → 4x₂ = 4x₁ → x₁ = x₂.
(b) Not onto. Consider y = 6. Suppose some x ∈ ℝ⁺ has g(x) = 6. Then 3x³ + 9 = 6, x³ = −1, x = −1, which is not positive. So no preimage exists.

Name a specific y for the disproof. For an onto proof, after solving for x you must show x is in the domain and substitute back.

MAMC · composition
g : A → B, f : B → C, and h(x) = f(g(x)) is a bijection. Which are guaranteed?
  1. g is onto
  2. f is onto
  3. g is one-to-one
  4. f is one-to-one

b and c.

(b) Let c ∈ C. Since h is onto, some a ∈ A has f(g(a)) = c. Let b = g(a) ∈ B. Then f(b) = c. So f is onto. (c) Suppose g(a₁) = g(a₂). Apply f: f(g(a₁)) = f(g(a₂)), i.e. h(a₁) = h(a₂). Since h is one-to-one, a₁ = a₂. So g is one-to-one. Counterexample to (a), (d): A = {a}, B = {b₁, b₂}, C = {c}, g(a) = b₁, f(b₁) = f(b₂) = c. h is a bijection, g misses b₂, f is not one-to-one.
MAMC · countability
Which are countably infinite?
  1. ℝ − ℤ
  2. ℝ − {x ∈ ℝ | |x| > 10}
  3. ℚ ∪ (ℤ × ℤ × ℤ)
  4. ℚ⁺ − ℤ
  5. ℤ ∩ (ℤ × ℤ)

c and d.

(a) Removing countably many points from ℝ leaves it uncountable. (b) This is [−10, 10], an interval, uncountable. (c) Union of two countable sets. (d) A subset of ℚ, infinite. (e) Integers and ordered pairs share no elements, so the intersection is ∅, finite.

“Countable” includes finite. “Countably infinite” does not.

Common mistakes

Collected from the staff notes in both practice exam solution keys.

Quantifiers and disproofs

  • Trying to disprove a “for all” with a general argument instead of one concrete counterexample.
  • Using an arbitrary object (“let S be a set with |S| = 99”) where a specific counterexample is required.
  • Using specific numbers for x and y when the claim is about all x and y.
  • Jumping from “no two elements share a remainder” to s − t ≢ 0 without stating s ≢ t first.

Rationals and parity

  • Asserting rational + rational = rational without proof when the problem did not grant it.
  • Claiming 2a/b “must be even” when it may not even be an integer.
  • Forgetting a case: x rational and y irrational is a different case from x irrational and y rational.
  • Using WLOG across cases that are not symmetric (a and b are not interchangeable in a² − 4b).
  • Wrong negation of “exactly one of x, y is rational”.

Functions

  • Not stating the domains of a and b, or stating them after using them.
  • Defining one-to-one backwards (a = b → f(a) = f(b)), or using horizontal-line-test or calculus arguments.
  • Onto proofs that solve for a but never show a is in the domain or substitute back to confirm f(a) = b.
  • Mis-composing piecewise functions: after applying f once, re-check which branch the output falls in.
  • Disproving onto using cardinality hand-waving instead of a specific missed output.

Modular arithmetic

  • Stopping at the inverse (x ≡ −9) instead of multiplying both sides of the original congruence by it.
  • Multiplying one side by the inverse and the other by the original coefficient.
  • Combining coefficients wrong on the way back up the EEA (e.g. 11 − 2(27 − 2·11) is 5·11 − 2·27, not 3·11 − 2·27).
  • Dropping a minus sign; always check the final x by substituting.
  • Reducing an exponent mod m instead of using a known power ≡ 1 (2¹⁰¹ mod 7 is not 2³ because 101 ≡ 3 mod 7).

Sets

  • Reading A ⊄ C as “every element of A is outside C”. It means some element of A is outside C.
  • Using set identities when the problem says definitions only.
  • Forgetting that ∅ is a subset of every set and that P(S) always contains ∅.

Exam mechanics

  • Not announcing the proof style or the rephrased statement; those are rubric lines.
  • Using scratch-work reasoning (“solve for a”) inside the proof without substituting back.
  • Spending the first hour on multiple choice. Budget about 50 minutes for the 7 written questions.
  • Not shading bubbles. Only shaded answers are graded for MC.
