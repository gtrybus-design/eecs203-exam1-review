Lecture 1

Propositions, predicates, quantifiers

propositionpredicatedomainquantifier∀ for all∃ there existsproofevenodd

Definitions

  • A proposition is a statement that is either true or false. “2 + 2 = 4” is one; “Why does my knee hurt?” and “This statement is false” are not.
  • A predicate is a proposition with unspecified variables, like P(x): “x + 2 = 4”. It has no truth value until x is fixed or quantified.
  • A quantified proposition has three parts: quantifier, domain, predicate. “For all integers x, x(x + 2) ≥ −1.”
  • ∀x P(x) P is true for every x in the domain. ∃x P(x) P is true for at least one x.
  • Domains: ℤ integers, ℤ⁺ positive integers {1, 2, 3, …}, ℕ naturals {0, 1, 2, …} (includes 0 in this course), ℚ rationals, ℝ reals. x ∈ S means x is an element of S.
  • Even: x = 2k for some integer k. Odd: x = 2k + 1 for some integer k. Every proof about parity goes through these equations.
Model proof from Lecture 1: for all positive integers n, n² − n is even.
Let n be an arbitrary positive integer. Factor n² − n = n(n − 1). One of n and n − 1 is even and the other is odd, and an even times an odd integer is even. So n² − n is even.

Checking n = 1, 2, 3 builds intuition but is not a proof of a “for all”. Pictures help but are not proofs either.

How it shows up on exams

  • “Which of these are propositions / predicates?”
  • “Is this quantified proposition true or false?” with a one-line reason.
  • Writing a short direct proof from the definition of even or odd.

Name one counterexample in the domain and show P(x) fails there.
  • A disproof of P is a proof of ¬P. Those are the same task.
  • d | n (“d divides n”) means n = dk for some integer k. “x is a multiple of y” means the same thing with roles swapped.

Nested quantifiers: process outside in

  • Handle the outer quantifier first, then the inner one. A later choice may depend on everything declared before it.
  • ∀x ∃y: “Let x be arbitrary. Let y = (something built from x).” The y you pick can depend on x.
  • ∃y ∀x: the single y must work for every x. To disprove: “Let y be arbitrary. Let x = (something built from y)” that breaks it.
  • Order matters. ∀x ∃y (4x − y = 0) is true (y = 4x). ∃y ∀x (4x − y = 0) is false (take x = y + 1).
  • If your witness must be in a restricted domain (an odd integer, a positive real), say why it is. The staff deducts for skipping this.
Prove: for all integers x there is an odd integer y with 3 | (x + y).
Let x be any integer. Consider y = 2x + 3. y is odd because y = 2(x + 1) + 1 and x + 1 is an integer. x + y = 3x + 3 = 3(x + 1), and x + 1 is an integer, so 3 | (x + y).

Watch out

  • Using a specific number when the statement is about every x. “Let x = 5” proves nothing about all integers.
  • Disproving a ∀ with a general argument. One concrete counterexample, with the arithmetic shown, is what earns the points.
  • Claiming “6 | 12 and 4 | 12 so 24 | 12.” y = 12 is the classic counterexample for “divisible by 4 and 6 implies divisible by 24.”

  • Lecture's tip: the negation is exactly what you would need to show to disprove the statement.
  • Domain restrictions stay put. The negation of “for all integers a not relatively prime to m, …” starts “there exists an integer a not relatively prime to m such that …”. The restriction does not flip.
  • Negate layer by layer from the outside. An inner “not” cancels against the negation rather than compounding.

Proof by contrapositive

  • “If p then q” is equivalent to “if ¬q then ¬p”. Proving the second proves the first.
  • Use it when the hypothesis is awkward (“x² is even”) and the conclusion is easy to assume (“x is even”), or when a direct attempt stalls after one line.
  • Course rule, stated on the slides: whenever you use a proof style, (1) announce it and (2) write the rephrased statement before any algebra.
Prove: for all integers x, if x² is even then x is even.
We will show the contrapositive: for all integers x, if x is odd then x² is odd. Let x be any odd integer, so x = 2k + 1 for some integer k. x² = 4k² + 4k + 1 = 2(2k² + 2k) + 1. Since 2k² + 2k is an integer, x² is odd.

If and only if

  • p ↔ q means (p → q) and (q → p). Prove both directions, labeled “(⇒)” and “(⇐)”, each by any style you like.
  • To disprove an iff, show one direction fails: a case with p true and q false, or p false and q true.

Translating English to logic

  • “Every A is B” → ∀x (A(x) → B(x)). A restricted domain under a ∀ becomes an implication.
  • “Some A is B” → ∃x (A(x) ∧ B(x)). A restricted domain under an ∃ becomes an and.
  • “There is someone who knows everyone who likes 203” → ∃x ∀y (L(y) → K(x, y)). The ∃ person is fixed first, then the ∀ ranges over the restricted group.
  • Lecture's red flag: an implication sitting directly inside an ∃ using the ∃ variable (“∃x (L(x) → …)”) is almost always a wrong translation. It is true as soon as one person fails the hypothesis.
  • “Every large enough integer has property P” → ∃N ∀x (x ≥ N → P(x)). The threshold comes first because it must not depend on x.
  • “Exactly one x has P” → ∃x (P(x) ∧ ∀y (P(y) → y = x)).

How it shows up on exams

Lecture 5

Proof by contradiction, rationals and irrationals

rationalirrationalproof by contradictioncontradiction

The method

  • To prove P: assume ¬P and derive something known to be false. Then ¬P must be false, so P is true. (Logic: ¬P → F is true only if ¬P is false.)
  • Write “Seeking contradiction, suppose the negation: …” and write the negation out explicitly. For a ∀ statement that negation starts “there exist … such that …”.
  • End by naming the contradiction: “This contradicts that k − j is an integer,” or “that √2 is irrational,” or a fact given in the problem.
  • Good contradictions: an integer equals a non-integer (1/a with a > 1, 1/6), a number is both even and odd, a rational number is irrational, a < a.
  • When to use it: statements of the form “x ≠ …”, “a does not divide …”, “z is irrational”, “there is no …”. Negating these gives you an equation to work with.

Rationals

  • Rational: x = a/b for integers a, b with b ≠ 0. Irrational: not rational. Every proof uses this fraction form.
  • √2 is irrational may be used without proof unless the problem says otherwise. The proof: suppose √2 = a/b in lowest terms, then a² = 2b², so a is even (by the contrapositive lemma), a = 2c, so b² = 2c², so b is even, contradicting lowest terms.
  • “Rational + rational is rational,” “rational × rational is rational,” and “rational + irrational is irrational” must be proved from a/b unless the problem grants them. The practice exam key specifically flags assuming these.
  • Irrational + irrational can be rational (√2 + (−√2) = 0). Irrational × irrational can be rational (√2 · √2 = 2).
Prove: for all integers a, b, 18a + 6b ≠ 1.
Seeking contradiction, suppose there exist integers a, b with 18a + 6b = 1. Dividing by 6: 3a + b = 1/6. But 3a + b is an integer and 1/6 is not. This is a contradiction, completing the proof.
Prove: if x, y are rational and x − y + 3z is irrational, then z is irrational.
Seeking contradiction, suppose x, y, z are all rational with x − y + 3z irrational. Write x = a/b, y = c/d, z = e/f (integers, nonzero denominators). Then x − y + 3z = (adf − cbf + 3bde) / (bdf), a ratio of integers with bdf ≠ 0, so it is rational. This contradicts that x − y + 3z is irrational.
Lecture 6 (and 7)

Proof by cases, WLOG, primes

proof by caseswithout loss of generalityprimeinfinitely many primes

Cases

  • Split the domain into cases that together cover everything (even/odd; negative/zero/positive; rational/irrational for each of two variables; remainder 0, 1, 2 mod 3).
  • Say “we use cases on …”, label each case, and finish each one with the exact form the conclusion needs (for “even”, literally 2·(integer)).
  • Close with “in every case, …”.
  • Cases combine with the other styles: contrapositive then cases (Lecture 15 Proof 5), contradiction then cases.

WLOG

  • “Without loss of generality, suppose x is even” is allowed only when the cases are identical by symmetry, meaning x and y play interchangeable roles in every part of the statement.
  • Practice exam key: in a² − 4b the variables are not symmetric, so “a even, b odd” and “a odd, b even” are different cases. Write both.
  • Using WLOG is never required. Writing every case is always acceptable.

Primes

  • Prime: an integer n > 1 with no divisor d satisfying 1 < d < n. The exam gives this definition.
  • Euclid's argument (seen in lecture and HW 3): suppose finitely many primes p₁, …, pₙ. Let N = p₁p₂⋯pₙ + 1. No pᵢ divides N (remainder 1), so N has a prime factor not on the list. Contradiction. Uses the fact that if a | b and a > 1 then a ∤ (b + 1).
Prove: for all integers x, 3x(x + 5) is even.
Let x be any integer. We use cases on the parity of x. Case 1: x even, x = 2k. Then 3x(x + 5) = 2·[3k(2k + 5)], an integer times 2. Case 2: x odd, x = 2k + 1. Then x + 5 = 2(k + 3), so 3x(x + 5) = 2·[3(2k + 1)(k + 3)]. In both cases 3x(x + 5) is even.

Watch out

  • Missing a case (forgetting zero when splitting on sign, or only doing x even).
  • Ending a case with “so it's even” without displaying the 2·(integer) form.
  • Combinatorial game theory from Lecture 7 is bonus material and is not on Exam 1.
Lecture 8

Sets

set-builder notationcardinality |S|∪ ∩ − complement⊆ subset⊊ proper subsetpower set P(S)Cartesian product ×disjointpartitionset equality

Definitions

  • Sets are unordered and have no repeats: |{1, 1, 2, 3}| = 3. Elements can be anything, including sets: |{a, {e}, {i, o}, u}| = 4.
  • Set-builder: {x ∈ ℤ | x is odd and x is prime}. Left of the bar is the domain, right of the bar is the predicate. Alternate form {2k | k ∈ ℤ}.
  • Union x ∈ S ∪ T iff x ∈ S or x ∈ T. Intersection x ∈ S ∩ T iff x ∈ S and x ∈ T. Difference x ∈ S − T iff x ∈ S and x ∉ T. Complement S̄ = U − S, relative to a universe U.
  • Subset S ⊆ T iff ∀x (x ∈ S → x ∈ T). ∅ ⊆ S for every S. S ⊆ S. Proper subset S ⊊ T means S ⊆ T and S ≠ T.
  • Equality S = T iff S ⊆ T and T ⊆ S. This is how set equality is proved: two subset proofs.
  • Power set P(S) is the set of all subsets of S. |P(S)| = 2|S|. P({1, 2}) = {∅, {1}, {2}, {1, 2}}. ∅ ∈ P(S) always, so P(S) is never empty.
  • Cartesian product A × B = {(a, b) | a ∈ A, b ∈ B}, ordered pairs. |A × B| = |A|·|B|. A × B × C gives triples.
  • Disjoint: S ∩ T = ∅. Partition of S: nonempty pieces, pairwise disjoint, whose union is S.
  • Set operations mirror logic: ∪ is ∨, ∩ is ∧, complement is ¬, ⊆ is →. So the set identities (De Morgan: complement of A ∪ B is Ā ∩ B̄, distributive, etc.) are the logic laws with symbols swapped.

How to write a subset proof

Let x be an arbitrary element with x ∈ [left side]. … unpack with the definitions of ∪, ∩, −, ⊆ one step at a time, citing “by definition of union” etc.; split into cases at an “or” … So x ∈ [right side]. Therefore [left] ⊆ [right] by definition of subset.
  • If the problem says “using only definitions,” you may not cite set identities or logical equivalence laws. Everything goes through element-chasing.
  • For a disproof of a set statement, give specific small sets (like A = {1}, B = {1, 2}) and show the failure concretely.
B ⊆ C. Prove (C − B) ∪ (B − A) ⊆ C.
Let x ∈ (C − B) ∪ (B − A). By definition of union, x ∈ C − B or x ∈ B − A. Case 1: x ∈ C − B. Then x ∈ C and x ∉ B, so x ∈ C. Case 2: x ∈ B − A. Then x ∈ B. Since B ⊆ C, x ∈ C by definition of subset. In every case x ∈ C, so (C − B) ∪ (B − A) ⊆ C.

Watch out

  • A ⊄ C means some element of A is outside C, not that all of A is outside C.
  • ∈ versus ⊆: 1 ∈ {1, 2} but {1} ⊆ {1, 2}. ∅ ⊆ S always; ∅ ∈ S only if S lists ∅ as an element.
  • |{∅}| = 1, |∅| = 0. |P(∅)| = 1.
  • Disproving “for all sets A, B, …” needs one concrete counterexample, not an argument about arbitrary sets.
Lecture 9

Modular arithmetic

a ≡ b (mod m)a mod msubstitution lawsfast modular exponentiation

Two meanings of “mod”

  • Equivalence mod a ≡ b (mod m) is a predicate on three integers. Three equivalent definitions, use whichever fits the proof: m | (a − b); a = b + km for some integer k; a and b have the same remainder on division by m.
  • Remainder mod a mod m is the integer in {0, 1, …, m − 1} left over when a is divided by m. Negative numbers: −1 mod 3 = 2.
  • “(mod m)” on the right modifies the whole line, not just the right side. Every integer is equivalent to infinitely many others: … ≡ x − m ≡ x ≡ x + m ≡ …

Rules

  • Substitution: if a ≡ b (mod m) then a + c ≡ b + c and ac ≡ bc (mod m). So in any sum or product you may replace a number by anything equivalent to it, at any step. Reduce early and often.
  • Hence an ≡ bn when a ≡ b. The reverse is false: 1² ≡ 4² (mod 5) but 1 ≢ 4.
  • You may not divide both sides, and you may not reduce an exponent mod m. (2101 mod 7 is not 2³ just because 101 ≡ 3 mod 7. The exponent reduces by Fermat, below, mod 6.)
  • In proofs, “x ≡ 2 (mod 3)” unpacks to “x = 3k + 2 for some integer k”, and you finish with algebra.

Computing big powers

  • First look for a small power that is ≡ 1 or ≡ −1. Then peel it off: 443 mod 15: 4² = 16 ≡ 1, so 443 = 4 · (4²)21 ≡ 4 · 1 = 4.
  • Otherwise repeated squaring: compute a¹, a², a⁴, a⁸, … reducing mod m after each square, write the exponent in binary, multiply the needed pieces, reduce.
Lecture 9 example: 592 · (1033 + 734)² mod 5
592 ≡ 2, 1033 ≡ 3, 734 ≡ 4 (mod 5) 592 · (1033 + 734)² ≡ 2 · (3 + 4)² ≡ 2 · 7² ≡ 2 · 2² = 8 ≡ 3

How it shows up on exams

  • Single-answer: compute an mod m or a messy expression mod m.
  • Multiple-answer: “which of these guarantee a ≡ b (mod m)?” (adding the same c: yes; multiplying by 2: no unless 2 is invertible; squaring: no; am−1 ≡ bm−1 with m prime: no.)
  • Proofs: parity or divisibility by cases on remainder, e.g. n² mod 4 is 0 or 1.
Lecture 10

Modular inverses, gcd, Extended Euclidean Algorithm, Fermat

modular inversegcdrelatively primeExtended Euclidean AlgorithmFermat's Little Theoremlinear congruence

Inverses

  • The inverse of a mod m is the integer b in {0, …, m − 1} with ab ≡ 1 (mod m). Written a⁻¹.
  • Theorem: a has an inverse mod m iff gcd(a, m) = 1 (a and m are relatively prime). So mod a prime p, every a ≢ 0 has an inverse.
  • Linear congruence ax ≡ c (mod m): exactly one solution in {0, …, m − 1} iff gcd(a, m) = 1. Otherwise either no solutions (2x ≡ 5 mod 15) or several (3x ≡ 6 mod 15 has x = 2, 7, 12). You will not be asked to find the several.
  • Solve by multiplying both sides by a⁻¹: 3x ≡ 2 (mod 10), 3⁻¹ = 7, so x ≡ 14 ≡ 4. Check: 3·4 = 12 ≡ 2.

Finding the inverse

  • Guess and check for small m: try a·1, a·2, … until you hit 1.
  • Educated guess for larger m: does a divide m + 1? 2m + 1? 3m + 1? … (4 divides 100 = 3·33 + 1, so 4⁻¹ ≡ 25 mod 33.)
  • Extended Euclidean Algorithm for anything: run Euclid down to 1 recording each remainder as an equation, then substitute back up to write 1 = s·m + t·a. Then t is the inverse of a (reduce t into {0, …, m − 1} if asked). Based on gcd(a, b) = gcd(a, b − a), or more quickly gcd(a, b) = gcd(b, a mod b).
Solve 15x ≡ 2 (mod 34).
Down: 34 = 2·15 + 4 so 4 = 34 − 2·15 15 = 3·4 + 3 so 3 = 15 − 3·4 4 = 1·3 + 1 so 1 = 4 − 3 gcd = 1, inverse exists Up: 1 = 4 − 3 = 4 − (15 − 3·4) = 4·4 − 15 = 4·(34 − 2·15) − 15 = 4·34 − 9·15 So −9·15 ≡ 1 (mod 34): 15⁻¹ ≡ −9 ≡ 25. Multiply both sides: x ≡ −9·2 = −18 ≡ 16 (mod 34). Check: 15·16 = 240 = 7·34 + 2 ✓

Fermat's Little Theorem

  • For a prime p and any integer a: ap ≡ a (mod p). If also p ∤ a: ap−1 ≡ 1 (mod p).
  • Use it to shrink exponents mod p − 1: 2101 mod 7: 2⁶ ≡ 1, 101 = 6·16 + 5, so 2101 ≡ 2⁵ = 32 ≡ 4.
  • Only valid when the modulus is prime and p ∤ a. For a composite modulus, look for a power ≡ 1 by hand instead.
  • HW 5 proved it: the sets {1, …, p − 1} and {a·1 mod p, …, a·(p − 1) mod p} are the same, so their products agree, giving (p − 1)! ≡ ap−1(p − 1)! and cancelling the invertible (p − 1)!.

Watch out (all from the practice exam keys)

  • Stopping at the inverse. “x ≡ −9” is the inverse of 15, not the solution. Multiply both sides of the original congruence by it.
  • Multiplying one side by the inverse and the other by the original coefficient.
  • Arithmetic on the way back up: 11 − 2(27 − 2·11) is 5·11 − 2·27, not 3·11 − 2·27. Keep each line in the form (coefficient)·m + (coefficient)·a.
  • Sign slips. Always check the final x by plugging back in.
  • Reducing an exponent mod m instead of mod p − 1.
Lecture 11

Functions and their properties

function f : A → Bdomaincodomainrange f(A)one-to-one (injective)onto (surjective)bijectioncompositioninverse function

Definitions

  • f : A → B is a function iff every element of A maps to exactly one element of B. Not a function: f(x) = 1/x on ℝ (0 has no output); “parent of x” (two outputs). Fine: a constant function, or a codomain element hit many times or never.
  • Domain A: inputs. Codomain B: allowed outputs. Range f(A) ⊆ B: outputs actually hit.
  • Onto: ∀b ∈ B ∃a ∈ A, f(a) = b. Every codomain element is hit at least once. Range equals codomain.
  • One-to-one: ∀a₁, a₂ ∈ A, f(a₁) = f(a₂) → a₁ = a₂. Every codomain element is hit at most once. Contrapositive form: a₁ ≠ a₂ → f(a₁) ≠ f(a₂), which is the form to use for disproofs.
  • Bijection: onto and one-to-one. Every codomain element hit exactly once. f⁻¹ : B → A exists iff f is a bijection, and f⁻¹(b) = a iff f(a) = b.
  • Changing the domain or codomain changes the answer: x² is not onto ℝ, is onto ℝ≥0, is one-to-one on ℝ⁺ but not on ℝ.

How to write each proof

Onto proof
Let b ∈ B be arbitrary. [scratch: solve f(a) = b for a] Let a = (formula in b). a ∈ A because … (check the domain!) f(a) = … = b. So f is onto.
Onto disproof
Consider b = (specific value). Suppose some a ∈ A has f(a) = b. Then … a = (value) which is not in A, or no real a works. So nothing maps to b; f is not onto.
One-to-one proof
Let a₁, a₂ ∈ A with f(a₁) = f(a₂). … algebra (state domain facts you use, like 4x + 5 ≠ 0) … So a₁ = a₂. Hence f is one-to-one.
One-to-one disproof
Consider a₁ = (value), a₂ = (different value), both in A. Then f(a₁) = … = f(a₂) but a₁ ≠ a₂. So f is not one-to-one.

Abstract functions and composition

  • For h(x) = f(g(x)) with g : A → B, f : B → C: if h is one-to-one then g is one-to-one; if h is onto then f is onto. The other two are not guaranteed (A = {a}, B = {b₁, b₂}, C = {c}, g(a) = b₁, f(b₁) = f(b₂) = c).
  • Proof of “h onto ⇒ f onto”: let c ∈ C; h onto gives a with f(g(a)) = c; set b = g(a) ∈ B; then f(b) = c.
  • Proof of “h one-to-one ⇒ g one-to-one”: if g(a₁) = g(a₂), apply f to get h(a₁) = h(a₂), so a₁ = a₂.
  • Functions on sets: f(S, T) = S ∪ T from P(A) × P(B) to P(U) can be a bijection, non-injective, or non-surjective depending on A, B, U, but never has an empty domain since (∅, ∅) is always an input.
  • Piecewise functions: after one application, re-check which branch the output lands in before applying again.

Watch out (from the practice exam keys)

  • Not declaring the domain of a₁, a₂ (or b), or declaring it after use.
  • Writing the one-to-one definition backwards (a = b → f(a) = f(b) is true of every function).
  • Horizontal line test, “strictly increasing,” or derivatives are not proofs in this course.
  • Onto: solving for a but never checking a ∈ A, or never substituting back to show f(a) = b.
  • Disproving onto with cardinality talk instead of one specific missed output.
Lecture 12

Countability

|A| ≤ |B||A| = |B|countablecountably infinite ℵ₀uncountableSchröder–Bernsteindiagonalization

Comparing infinite sets with functions

  • |A| ≤ |B| iff there is a one-to-one f : A → B. |A| ≥ |B| iff there is an onto f : A → B. |A| = |B| iff there is a bijection.
  • Schröder–Bernstein: if |A| ≤ |B| and |B| ≤ |A| then |A| = |B|. So two one-to-one maps, one each way, prove equal cardinality without building a bijection.
  • Countable: |S| ≤ |ℤ⁺|, i.e. S is finite or its elements can be listed s₁, s₂, s₃, … so that every element appears at a finite position. Countably infinite: |S| = |ℤ⁺| = ℵ₀. Uncountable: |S| > |ℤ⁺|.
  • “Countable” includes finite sets. A multiple-answer question asking for “countably infinite” excludes ∅ and finite sets.

Facts you may use without proof (HW 6 reminders)

Countable

  • ℕ, ℤ, ℤ⁺, ℚ, ℚ⁺
  • ℤ × ℤ and any finite product of countable sets (zigzag through the grid)
  • A union of two, or countably many, countable sets
  • Any subset of a countable set
  • Finite sets, the primes, the even integers, the set of finite-length strings

Uncountable

  • ℝ, [0, 1], any interval such as [−10, 10] or (0, 1)
  • ℝ − ℚ (the irrationals), ℝ − ℤ, ℝ minus any countable set
  • P(ℤ), P(ℕ): the power set of an infinite set is always strictly bigger
  • Infinite binary sequences
  • Any set that contains an uncountable subset
  • Standard bijections to recognise: ℤ⁺ → ℕ by n ↦ n − 1; ℤ⁺ → ℤ by alternating 0, 1, −1, 2, −2, …; ℤ⁺ → ℤ⁺ × ℤ⁺ by diagonals; (0, 1) → ℝ by a stretching function.
  • Intersections can collapse: ℤ ∩ (ℤ × ℤ) = ∅ because integers are not ordered pairs.

Diagonalization: [0, 1] is uncountable

Seeking contradiction, suppose some f : ℤ⁺ → [0, 1] is onto. List f(1), f(2), f(3), … as infinite decimals in a table. Let d be the diagonal number: its i-th digit is the i-th digit of f(i). Let s be the shifted diagonal: add 5 to every digit of d (9 rolls over to 4, etc.). s ∈ [0, 1], but for every i the i-th digit of s differs from the i-th digit of f(i), so s ≠ f(i) for all i. Then f is not onto. Contradiction.
  • General shape: table the items, read the diagonal, alter every diagonal entry, and the new row differs from row i in position i, so it is missing from the table.
  • Shifting by 5 (rather than by 1) avoids the 0.4999… = 0.5000… ambiguity.

How it shows up on exams

  • Multiple-answer: which of these sets are countable / countably infinite.
  • Short answer: show |A| = |B| by giving a bijection, or two one-to-one maps plus Schröder–Bernstein.
  • Explain a step of the diagonalization proof or why a proposed listing misses something.
Before you walk in

Last-ten-minutes checklist

  1. Prove ∃: name a witness and check it is in the domain. Prove ∀: arbitrary element. Disprove ∀: one counterexample. Disprove ∃: generic argument.
  2. Nested quantifiers outside in. Later choices may depend on earlier variables, never the reverse.
  3. Negation of “if p then q” is “p and not q”. Negation of iff is “exactly one side holds”. Domain restrictions do not flip.
  4. Announce every proof style and write the rephrased statement: “We show the contrapositive: …” / “Seeking contradiction, suppose …” / “We use cases on …”.
  5. Cases must cover everything. WLOG only under true symmetry. End each case in the exact required form.
  6. Rational means a/b with b ≠ 0. Prove closure facts from fractions unless granted. √2 irrational is granted.
  7. Subset proofs are element-chasing: “Let x ∈ left … so x ∈ right.” Set equality is two subset proofs. A ⊄ C means some element escapes.
  8. |P(S)| = 2|S|. |A × B| = |A||B|. ∅ ⊆ everything; (∅, ∅) is always in P(A) × P(B).
  9. Mod: substitute freely in sums and products, reduce early, never divide, never reduce an exponent mod m. Look for a power ≡ ±1 first.
  10. Inverse exists iff gcd(a, m) = 1. EEA: down to 1, back up as (coef)·m + (coef)·a, then multiply both sides and check.
  11. Fermat: ap−1 ≡ 1 (mod p) for prime p ∤ a. Exponents reduce mod p − 1.
  12. One-to-one: f(a₁) = f(a₂) → a₁ = a₂, with domains stated first. Onto: arbitrary b, construct a, show a ∈ A, substitute back. Disproofs use specific values.
  13. Composition: h one-to-one ⇒ g one-to-one; h onto ⇒ f onto. Nothing else is guaranteed.
  14. Countable: ℕ, ℤ, ℚ, products, unions, subsets. Uncountable: ℝ, intervals, ℝ minus countable, power sets of infinite sets. Countable includes finite.
  15. Multiple-answer questions lose 2 points per error; judge every option independently. MC first, then short answer, then a solid block for free response. Shade the bubbles.
