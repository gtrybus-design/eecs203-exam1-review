Lectures 2–3 · the grid behind every proof

Four moves for every ∀ and ∃

To prove

To disprove

∃x P(x)

Name one specific x in the domain. Show P(x) is true. Show x is in the domain.

Let x be arbitrary. Show P(x) fails for that generic x.

∀x P(x)

Let x be arbitrary. Argue P(x) using only that x is in the domain.

Name one counterexample. Show P(x) is false there.

Nested quantifiers go outside in. A later ∃ may depend on earlier ∀ variables, never the reverse. Checking examples is never a proof of a ∀.

Lectures 3, 5, 6 · announce the style

Four proof templates

Direct

Default. Unpack, do algebra, land on the definition.

Let x be arbitrary with [hypothesis].
So x = 2k for some integer k.
… algebra … = 2(integer).
So [conclusion].

Contrapositive

Hypothesis is awkward, conclusion is easy to assume.

We show the contrapositive:
“if not q, then not p.”
Let x be arbitrary with not q.
… direct proof … so not p.

Contradiction

Claims with ≠, “not divisible”, “irrational”, “no x”.

Seeking contradiction, suppose
“there exist … with … and not q.”
… derive something false …
This contradicts [name it].

Cases

Domain splits: even/odd, sign, remainder mod 4.

We use cases on the parity of x.
Case 1: x = 2k … [conclusion].
Case 2: x = 2k+1 … [conclusion].
In every case, [conclusion].

Rule from lecture: write the rephrased statement before any algebra. That is where rubric points live.

Speaker notes

Whenever you use a style, do two things: announce it, and write down the statement you will actually prove. For contrapositive that is the flipped if-then. For contradiction that is the full negation, with the quantifier turned over. For cases, say what you are splitting on and make sure the cases cover everything.

Parity · Lecture 15, Proof 1

If 3x − 4y is even, then x is even

Cover the proofs. Three styles all work. State each style and its first line.

Direct

Let x, y be integers
with 3x − 4y = 2k.
Then 3x = 2k + 4y,
so x = 2k + 4y − 2x
   = 2(k + 2y − x).
k + 2y − x is an integer,
so x is even.

Contrapositive

We show: if x is odd,
then 3x − 4y is odd.
Let x = 2k + 1. Then
3x − 4y = 6k + 3 − 4y
   = 2(3k − 2y + 1) + 1.
That is odd. ∎

Contradiction

Suppose 3x − 4y is
even and x is odd.
Let x = 2k + 1. Then
3x − 4y
   = 2(3k − 2y + 1) + 1,
which is odd. This
contradicts “even”.

Trap. Announce the style and write the rephrased claim first. Keep x and y arbitrary; never plug in numbers.

Source: Lecture 15 review, Proof 1

Speaker notes

Even/odd definitions: x is even if x = 2k, odd if x = 2k + 1, for an integer k. The contrapositive is usually the cleanest here because assuming x is odd gives you something concrete, while assuming 3x − 4y is even gives you an equation with two unknowns. All three versions finish by exhibiting the form 2 times an integer, or 2 times an integer plus 1.

Cases · Lecture 15, Proof 4

3x(x + 5) is even for every integer x

Cover the cases. What are you splitting on, and what exact form must each case end in?

Let x be any integer. We use cases on the parity of x.

Case 1: x is even

Let x = 2k for an integer k.
3x(x + 5) = 3(2k)(2k + 5)
  = 2 · [3k(2k + 5)].
The bracket is an integer,
so the product is even.

Case 2: x is odd

Let x = 2k + 1. Then
x + 5 = 2(k + 3), so
3x(x + 5) = 2 · [3(2k + 1)(k + 3)].
The bracket is an integer,
so the product is even.

Trap. Finish each case in the literal form 2 · (integer). Say “in both cases” at the end.

Source: Lecture 15 review, Proof 4

Speaker notes

Why cases: nothing about 3x(x+5) is obviously even until you know the parity of x. Even x makes the first factor x even. Odd x makes x + 5 even. Either way a factor of 2 shows up. The cases must cover every integer, which even and odd do. Never end a case with just "so it is even"; show the 2 times an integer.

Parity · Practice Exam 2, Problem 16 · 10 pts

If (x + 4)(y + 7) is odd, then x is ___ and y is ___

Two jobs: fill in the blanks, then prove it using the definitions of even and odd. Which style is shortest?

Step 1: the blanks

x + 4 is odd only if x is odd. y + 7 is odd only if y is even.

x odd, y even

Points: blanks 2, contrapositive 2, cases 2, algebra 4.

Step 2: contrapositive, then cases

We show: if x is even or y is odd, then (x + 4)(y + 7) is even.
Case 1: x even, x = 2k. Then (2k + 4)(y + 7) = 2(k + 2)(y + 7).
Case 2: y odd, y = 2m + 1. Then (x + 4)(2m + 8) = 2(x + 4)(m + 4).
Either way the product is even. ∎

Trap. Negating “x odd and y even” gives “x even or y odd”, an or, so you need cases. You can reuse k in a separate case.

Source: Practice Exam 2, Problem 16. Alternates: all four parity cases, or the product-is-odd lemma.

Speaker notes

Reading order: decide the answer first by asking when each factor can be odd. A product of two integers is odd only when both factors are odd. So x + 4 odd forces x odd, and y + 7 odd forces y even. For the proof, the contrapositive is "if x is even or y is odd, then the product is even". That is an or, so split into the two cases. In each case one factor is visibly even.

Contradiction · Practice Exam 2, Problem 15 · 10 pts

No integers a, b satisfy a² − 4b = 2

First line: write the negation exactly. Then find the false statement it forces.

Contradiction on parity

Suppose integers a, b exist with
a² − 4b = 2. Then a² = 2(2b + 1),
so a² is even, so a is even.
Let a = 2k. Then 4k² = 2(2b + 1),
so 2k² = 2b + 1. Even = odd.
Contradiction. ∎

Contradiction, cases mod 4

Suppose a² − 4b = 2. Mod 4, 4b ≡ 0,
so a² ≡ 2. Cases on a mod 4:
a ≡ 0: a² ≡ 0. a ≡ 1: a² ≡ 1.
a ≡ 2: a² ≡ 4 ≡ 0. a ≡ 3: a² ≡ 9 ≡ 1.
No case gives 2. Contradiction. ∎

Traps. Negation is “there exist a, b with a² − 4b = 2”, not “≠”. One example failing is not a contradiction. In a proof by cases, “a odd, b even” and “a even, b odd” are different cases, so no WLOG.

Source: Practice Exam 2, Problem 15 (five accepted solutions)

Speaker notes

The negation of "there do not exist a and b such that a squared minus 4b equals 2" is "there exist a and b such that a squared minus 4b equals 2". To contradict a there-exists you must derive something false from it for those a and b, not show that some values fail. The parity argument uses the Lecture 3 fact that if a squared is even then a is even. A third accepted route is cases on the parity of a alone, since 4b is always even.

Divisibility · Lecture 15, Proof 3

If a | b and a > 1, then a ∤ (b + 1)

Definition first: a | b means b = aj for some integer j. What is the negation you would assume?

Contradiction

Suppose integers a, b with a | b, a > 1,
and a | (b + 1). So b = aj, b + 1 = ak.
Then aj + 1 = ak, so 1 = a(k − j),
so k − j = 1/a. But k − j is an integer
and 1/a is not, since a > 1. ∎

Direct

Let a | b with a > 1, so b = am.
Then b + 1 = am + 1 = a(m + 1/a).
Since a > 1, 1/a is not an integer,
so m + 1/a is not an integer.
So a does not divide b + 1. ∎

Trap. The negation keeps both hypotheses: “a | b, a > 1, and a | (b + 1)”. The contradiction is an integer equal to a non-integer, and it only works because a > 1.

Source: Lecture 15 review, Proof 3. Same idea: 18a + 6b ≠ 1 (Lecture 5).

Speaker notes

The key fact is that an integer cannot equal a number between 0 and 1. The contradiction proof is quicker because subtracting the two divisibility equations isolates 1/a. Remember that the negation of a for-all-if-then statement is there-exist with the hypotheses AND the negated conclusion.

Rationals · Practice Exam 1, Problem 11 · 8 pts

If x + y is rational, then x, y are both rational or both irrational

Rational means a/b with integers a, b and b ≠ 0. You may not assume “rational + rational is rational”. Write the negation.

Running Rational

Suppose x + y is rational and exactly one
of x, y is rational. WLOG x is that one:
x = a/b and x + y = c/d (b, d ≠ 0).
Then y = c/d − a/b = (cb − da)/(db),
a ratio of integers, so y is rational.
Contradiction. ∎

Same move: x − y + 3z

Claim: x, y rational and x − y + 3z
irrational imply z irrational. Suppose z
is rational too: x = a/b, y = c/d, z = e/f.
Then x − y + 3z = (adf − cbf + 3bde)/(bdf),
a ratio of integers, so rational.
Contradiction. ∎

Trap. The negation is “exactly one is rational”, not “neither”. Show the fraction; do not cite closure facts the problem did not grant.

Sources: Practice Exam 1 Problem 11 (key uses WLOG, which is fine since x and y are symmetric); Lecture 15 Proof 2

Speaker notes

Negation of "x plus y rational implies both rational or both irrational" is "x plus y rational and exactly one of x, y rational". WLOG is legitimate here because the statement is symmetric in x and y. The whole proof is: subtract the known rational from the known rational sum and the leftover must be rational, contradicting irrationality. Write out the common denominator.

Irrationals · Practice Exam 1, Problem 14 · 8 pts

Prove that log₂(3) is irrational

Given: log_b(a) = x exactly when b^x = a, and log₂(3) > 0. Which style, and what do you do with the exponent a/b?

Proof by contradiction

Suppose log₂(3) = a/b, integers, b ≠ 0.
WLOG a, b > 0, since log₂(3) > 0.
By definition of log, 3 = 2^(a/b).
Raise both sides to the b: 3^b = 2^a.
3^b is odd and 2^a is even (a ≥ 1).
Even = odd. Contradiction. ∎

Where the points are

Negation 2 · a/b form 1 · log definition 1 · 3^b = 2^a 1 · positive a, b 1 · odd vs even 1 · contradiction 1.

Odd and even facts may be used without proof.

Traps. Do not say 2^(a/b) is even; it need not be an integer. Raise to the b first. Writing ln 3 / ln 2 proves nothing without more work.

Source: Practice Exam 1, Problem 14

Speaker notes

This is the same shape as the square root of 2 proof: assume a fraction, clear the exponent, and compare parity. Raising 2^(a/b) to the b is the move that turns a possibly non-integer into the integer 2^a. Positivity of a and b matters so that 2^a is an even integer and 3^b is an odd integer.

Contrapositive + cases · Lecture 15, Proof 5

If x − 2y is rational and xy is irrational, then x and y are both irrational

Given: sums and products of rationals are rational; a rational combined with an irrational is irrational. Flip it with De Morgan.

Scratch: the flip

not(both irrational) becomes “x or y is rational”.

not(x − 2y rational and xy irrational) becomes “x − 2y irrational or xy rational”.

Proof by contrapositive, with cases

We show: if x or y is rational, then x − 2y is
irrational or xy is rational.
Case 1: x rational, y irrational. 2y is irrational,
so x − 2y is irrational.
Case 2: x irrational, y rational. 2y is rational,
so x − 2y is irrational.
Case 3: both rational. Then xy is rational.
In every case the conclusion holds. ∎

Trap. Do not assume either side of the “or” inside a case. Each case must end by proving one of the two. All three cases are needed.

Source: Lecture 15 review, Proof 5 (Exam 1 style)

Speaker notes

Original: (x minus 2y rational AND xy irrational) implies (x irrational AND y irrational). Contrapositive: negate the conclusion to get x rational OR y rational, and negate the hypothesis to get x minus 2y irrational OR xy rational. The hypothesis of the contrapositive is an or, so it splits naturally into cases. Case 3 covers both rational, which is allowed by the or.

Sets · Lecture 15 sets proof · definitions only

Given B ⊆ C, prove (C − B) ∪ (B − A) ⊆ C

Subset proofs always start the same way. What is your first sentence, and how do you handle the “or”?

Definitions

S ⊆ T: for all x, x ∈ S → x ∈ T.

x ∈ S ∪ T: x ∈ S or x ∈ T.

x ∈ S − T: x ∈ S and x ∉ T.

Element-chase

Let x ∈ (C − B) ∪ (B − A).
By definition of union, x ∈ C − B or x ∈ B − A.
Case 1: x ∈ C − B. Then x ∈ C and x ∉ B. So x ∈ C.
Case 2: x ∈ B − A. Then x ∈ B. Since B ⊆ C, x ∈ C.
In every case x ∈ C. So the union is a subset of C. ∎

Trap. “Using only definitions” bans set identities and logic laws. Start from an arbitrary x in the left side, and cite the definition each time you use one.

Source: Lecture 15 review, Sets Proof. Pattern for every ⊆ proof.

Speaker notes

Skeleton for any subset proof: let x be arbitrary with x in the left set, unpack with definitions, split on any or, and end with x in the right set. The given B subset C is used exactly once, in Case 2. In Case 1 you do not need it at all.

Sets · Practice Exam 2, Problem 11 · 7 pts

Prove (A − B) ∪ (A ∩ B) = A

Equality means two subset proofs. Name both claims before you start. Which one needs the case split on x ∈ B?

Direction 1: left ⊆ A

Let x ∈ (A − B) ∪ (A ∩ B).
Case 1: x ∈ A − B. Then x ∈ A.
Case 2: x ∈ A ∩ B. Then x ∈ A.
So x ∈ A. Hence left ⊆ A.

Direction 2: A ⊆ left

Let x ∈ A. Split on whether x ∈ B.
Case 1: x ∈ B. Then x ∈ A ∩ B.
Case 2: x ∉ B. Then x ∈ A − B.
Either way x is in the union. ∎

Traps. Both directions are required; the second is not the first one backwards. Venn diagrams and set identities earn no credit. The two claims are left ⊆ A and A ⊆ left, not (A − B) ⊆ (A ∩ B).

Source: Practice Exam 2, Problem 11

Speaker notes

Set equality is proved by mutual inclusion. In direction 1 the case split comes from the union, so you split because the hypothesis is an or. In direction 2 there is no or in your hypothesis, so you create the split yourself on whether x is in B, and each case lands in a different piece of the union.

Sets · Practice Exam 1, Problem 12 · 8 pts

Prove or disprove, for all sets A, B, C

Decide prove or disprove for each, then recall: A ⊄ C means there exists x ∈ A with x ∉ C.

(a) A ⊆ B and B ⊄ C, so A ⊄ C

Disprove

Counterexample: A = ∅, B = {0}, C = {1}.
A ⊆ B and B ⊄ C, but A ⊆ C because
the empty set is a subset of every set.

(b) A ⊆ B and A ⊄ C, so B ⊄ C

Prove

A ⊄ C gives some x ∈ A with x ∉ C.
Since A ⊆ B, x ∈ B. So x ∈ B and x ∉ C,
which means B ⊄ C. ∎

Traps. (a) One concrete counterexample, not an argument about arbitrary sets. (b) Do not read A ⊄ C as “every x in A is outside C”. Cardinalities say nothing here.

Source: Practice Exam 1, Problem 12

Speaker notes

Part a is a for-all, so a single counterexample disproves it. The empty set makes a clean one. Part b: unpack the negated subset into its there-exists, then use the given subset relation on that specific witness. Do not take an arbitrary x in A and claim it is outside C; only some element is guaranteed to be.

Mod · Practice Exam 2, Problem 14 · 8 pts

Solve 27x ≡ 2 (mod 38) with the EEA

Three phases: Euclid down, substitute back up, then multiply both sides. Which one do students forget?

Down, up, multiply

38 = 1·27 + 11
27 = 2·11 + 5
11 = 2·5 + 1
1 = 11 − 2·5 = 11 − 2(27 − 2·11) = 5·11 − 2·27
  = 5(38 − 27) − 2·27 = 5·38 − 7·27
So 27⁻¹ ≡ −7. Multiply BOTH sides by −7:
x ≡ −14 ≡ 24 (mod 38). Check: 27·24 = 17·38 + 2.

Same recipe, Exam 1

20x ≡ 2 (mod 67): 1 = 3·67 − 10·20, so 20⁻¹ ≡ −10 and x ≡ −20 ≡ 47.

Check: 20·47 = 940 = 14·67 + 2.

Traps. Stopping at the inverse; multiplying one side only; combining coefficients wrong (11 − 2(27 − 2·11) is 5·11 − 2·27); dropping a sign. Trial and error earns no credit.

Sources: Practice Exam 2 Problem 14; Practice Exam 1 Problem 15

Speaker notes

The inverse exists because the gcd of 27 and 38 is 1, which the last nonzero remainder of 1 shows. Work back up keeping every line in the form (coefficient) times (modulus) plus (coefficient) times (the number). The coefficient of 27 in the final line is the inverse. Then multiply the original congruence on both sides, and always verify by plugging in.

Mod · Practice Exam 2, Problem 13 · 7 pts

x ≡ 17 (mod 14) and y ≡ 26 (mod 21). Prove xy ≡ 1 (mod 7)

Why does knowing x mod 14 tell you x mod 7? Use the definition a ≡ b (mod m) iff a = b + km.

Reduce, then substitute

x ≡ 17 ≡ 3 (mod 14), y ≡ 26 ≡ 5 (mod 21).
Since 7 | 14 and 7 | 21, x ≡ 3 and y ≡ 5
(mod 7). So xy ≡ 3 · 5 = 15 ≡ 1 (mod 7). ∎

From the definition

x = 3 + 14a = 3 + 7(2a), y = 5 + 7(3b).
xy = 15 + 7(9b + 10a + 42ab) = 15 + 7k.
So xy ≡ 15 ≡ 1 (mod 7). ∎

Trap. Say why you may drop from mod 14 to mod 7: 7 divides 14. Multiplying out (17 + 14a)(26 + 21b) works but wastes time.

Source: Practice Exam 2, Problem 13. Substitution laws: Lecture 9.

Speaker notes

Substitution law: if a is congruent to b mod m then a plus c and a times c are congruent to b plus c and b times c. The definition version makes the divisibility by 7 explicit by writing each number as a constant plus a multiple of 7. Both are accepted; the first is faster.

Mod + cases · Practice Exam 1, Problem 16 · 11 pts

Sets of 99 integers: differences and squares

For |S| = 100 the pigeonhole proof worked. For |S| = 99, decide prove or disprove for (a) s − t and (b) s² − t² being multiples of 99.

(a) s − t: Disprove

Take S = {0, 1, …, 98}, so |S| = 99.
For distinct s, t ∈ S: s − t ≠ 0 and
−99 < s − t < 99, so 99 ∤ (s − t).

(b) s² − t²: Prove

Case 1: some s ≠ t have s ≡ t (mod 99).
Then s² − t² ≡ 0.
Case 2: all residues differ, so all 99 occur.
Take s ≡ 1, t ≡ 10: s² − t² ≡ 1 − 100 ≡ 0.

Traps. (a) needs an explicit set, not an arbitrary S. “99 is not > 99” does not by itself make it false. (b) Cover both cases and justify the residue claim.

Source: Practice Exam 1, Problem 16

Speaker notes

Part b works because squaring merges residues: 1 and 10 have different residues mod 99 but the same square, 1 and 100. So 99 elements cannot give 99 different squares, and two squares must match. The case split is the clean way to say it: either two elements already agree mod 99, or all 99 residues appear and the pair 1 and 10 is forced.

Functions · Practice Exam 1 Problem 13a · Lecture 15

Proving a function is one-to-one

Definition: for all a₁, a₂ in the domain, f(a₁) = f(a₂) implies a₁ = a₂. Say the domain before you use a₁ and a₂.

f : ℝ⁺ → ℝ, f(x) = x⁴ − 2

Let a, b ∈ ℝ⁺ with f(a) = f(b).
Then a⁴ − b⁴ = 0, so
(a² + b²)(a + b)(a − b) = 0.
Since a, b > 0, a² + b² > 0 and a + b > 0.
So a − b = 0, i.e. a = b. ∎

f(x) = 3/(4x + 5), x ≠ −5/4

Let x₁, x₂ ∈ ℝ − {−5/4} with
f(x₁) = f(x₂). So 3/(4x₁ + 5) = 3/(4x₂ + 5).
Cross-multiply: 3(4x₂ + 5) = 3(4x₁ + 5).
So 4x₂ = 4x₁, hence x₁ = x₂. ∎

Traps. State both inputs’ domain first. No horizontal line test, no calculus. Do not write the definition backwards. To disprove, name two different inputs with the same output.

Sources: Practice Exam 1 Problem 13(a); Lecture 15 Onto and 1-1 proofs

Speaker notes

The only thing positivity buys you in the first proof is that the factors a squared plus b squared and a plus b are nonzero, which lets you cancel to get a minus b equals zero. If the domain were all reals the function would not be one-to-one: for example, 1 and negative 1 give the same output.

Functions · Practice Exam 2 Problem 12 · Practice Exam 1 Problem 13b

Proving and disproving onto

Definition: for all b in the codomain there exists a in the domain with f(a) = b. Prove with an arbitrary b; disprove with one named b.

f : ℝ⁺ → ℝ⁺, f(x) = √(2/x): onto

Scratch, off to the side: b = √(2/a) gives a = 2/b².

Let b ∈ ℝ⁺ be arbitrary. Let a = 2/b².
Since b² > 0, a > 0, so a ∈ ℝ⁺.
f(a) = √(2 / (2/b²)) = √(b²) = b. ∎

f : ℝ⁺ → ℝ, f(x) = x⁴ − 2: not onto

Any value ≤ −2 works, but name one.

Consider −2 ∈ ℝ. Suppose f(a) = −2 for
some a ∈ ℝ⁺. Then a⁴ = 0. But a > 0 gives
a⁴ > 0. Contradiction, so f is not onto. ∎

Traps. Show your a is in the domain, and substitute back to get f(a) = b. Disprove with a specific value, not a range. “|ℝ⁺| < |ℝ|” is false, so cardinality is no argument.

Sources: Practice Exam 2 Problem 12; Practice Exam 1 Problem 13(b). Also: 3x³ + 9 on ℝ⁺ misses 6.

Speaker notes

The staff note that the most common lost point on onto proofs was forgetting to show that the constructed a belongs to the domain. Also solve for a on scratch paper, then in the graded proof simply define a and verify f of a equals b. Doing the algebra backward inside the proof costs a point.

Functions · Lecture 15, composition

If h(x) = f(g(x)) is a bijection, what must hold?

g : A → B and f : B → C. Which of “g onto, f onto, g one-to-one, f one-to-one” are guaranteed? Prove two, disprove two.

f is onto

Let c ∈ C. Since h is onto, some a ∈ A
has f(g(a)) = c. Let b = g(a) ∈ B.
Then f(b) = c. So f is onto. ∎

g is one-to-one

Let g(a₁) = g(a₂). Apply f: h(a₁) = h(a₂).
h is one-to-one, so a₁ = a₂.
So g is one-to-one. ∎

g need not be onto; f need not be one-to-one

A = {a}, B = {b₁, b₂}, C = {c}, g(a) = b₁, f(b₁) = f(b₂) = c.
h is a bijection, but g misses b₂ and f sends b₁ and b₂ to c.

Source: Lecture 15 review, Onto and 1-1 with function composition. Answer: f onto, g one-to-one.

Speaker notes

Memory aid: the outer function inherits onto, the inner function inherits one-to-one. Onto only needs h onto to push through f; one-to-one only needs h one-to-one to pull back through g. The one-point counterexample shows the other two fail.

Functions · Practice Exam 2, Problem 17 · 12 pts

Reducing functions: prove for all f, disprove with one f

f is reducing if f(x) < x for all x. It is absolutely reducing if f(x) < |x| for all x. For each, g(x) = f(f(x)): prove or disprove?

(a) reducing: Prove

Let f be an arbitrary reducing function
and x any real. Then f(x) < x. Applying
“reducing” at the input f(x): f(f(x)) < f(x).
So f(f(x)) < f(x) < x. ∎

(b) absolutely reducing: Disprove

Let f(0) = −10, f(−10) = 1,
f(x) = −1 otherwise. Then f(0) < 0,
f(−10) = 1 < 10, and −1 < |x| elsewhere.
But g(0) = f(−10) = 1, not < |0|. ∎

Traps. (a) Do not pick an example like x − 1; you must handle every reducing f. Cite “reducing” at f(x); do not apply f to both sides of an inequality. (b) Define f at every real, and re-check which branch applies after the first f.

Source: Practice Exam 2, Problem 17

Speaker notes

Part a has a for-all over functions, so use an arbitrary function and an arbitrary real. The step that does the work is instantiating the reducing property at the input f of x. Part b only needs one fully defined piecewise function. Compose carefully: after applying f to 0 you land on negative 10, so the next application uses the negative-10 branch.

Countable or uncountable?

Countable means |S| ≤ |ℤ⁺|, which includes finite sets. Countably infinite excludes finite sets.

Countable

ℕ, ℤ, ℚ, ℚ⁺

ℤ × ℤ and any finite product of countable sets

Unions of countable sets; any subset of a countable set

Finite sets, and the empty set

Uncountable

ℝ, [0, 1], any interval such as (0, 10)

ℝ − ℤ and ℝ − ℚ: remove countably many points and it stays uncountable

P(ℤ), the power set of an infinite set

Anything containing an uncountable subset

Comparing sizes with a function

|(0, 10)| ≤ |[1, 3]| needs a one-to-one f : (0, 10) → [1, 3]. So f(x) = x/5 + 1 and f(x) = x/10 + 1 both work. g(x) = 5(x − 1) fails: it sends 1 to 0, which is not in (0, 10), and it points the wrong way. Intersections can be empty: ℤ ∩ (ℤ × ℤ) = ∅.

Speaker notes

For any subset A of the integers: A cross A is countable, A union Z intersect A equals A is countable, A is not necessarily uncountable, and Z minus A is a subset of Z so it cannot be uncountable. Schroder-Bernstein: one-to-one maps in both directions give a bijection, so equal cardinality.

Countability · Lecture 12 · diagonalization

Why [0, 1] is uncountable

Explain it without looking: what is assumed, what is built from the diagonal, and why the new number is missing from the list.

The proof

Seeking contradiction, suppose f : ℤ⁺ → [0, 1]
is onto. List f(1), f(2), f(3), … as decimals.
Let d have as its i-th digit the i-th digit
of f(i). Let s be d with 5 added to every
digit, mod 10. Then s ∈ [0, 1], yet s differs
from f(i) in digit i for every i. So f misses
s, contradicting onto. ∎

An example table

f(1) = 0.531…
f(2) = 0.149…
f(3) = 0.726…
d    = 0.546…
s    = 0.091…

Adding 5 avoids the 0.4999… = 0.5000… ambiguity.

Trap. Onto is what you assume, because countable means a listing hits every element. The contradiction is that the listing misses s.

Source: Lecture 12 diagonalization proof (the only one you need to follow)

Speaker notes

General shape of any diagonalization: table the items, read the diagonal, alter each diagonal entry, and the new row cannot equal row i because it differs in position i. The same pattern shows the power set of the integers is uncountable, using bits instead of digits.

Seven questions before you write the last line
